# Agent Workflow

## Overview

VoyageAI Travel Planner uses a Master Agent to control the travel-planning process.

The Master Agent receives the user's travel information and sends the state through a sequence of specialized agents. Each agent handles one specific part of the travel plan.

## Master Agent

The Master Agent acts as the central controller of the system.

Its main responsibilities are:

1. Receive the user's travel information.
2. Pass the current state to the specialized agents.
3. Collect the results from each agent.
4. Return the final updated state.

## Agent Flow

The agents are executed in the following order:

```text
User Input
    ↓
Master Agent
    ↓
Weather Agent
    ↓
Budget Agent
    ↓
Hotel Agent
    ↓
Restaurant Agent
    ↓
Itinerary Agent
    ↓
Final Travel Plan

Specialized Agents
1. Weather Agent

The Weather Agent handles weather-related information for the selected destination.

It provides weather information that can help the user plan activities and travel arrangements.

2. Budget Agent

The Budget Agent handles the user's travel budget and helps classify or process the budget information used for planning.

3. Hotel Agent

The Hotel Agent handles hotel-related information for the selected destination.

4. Restaurant Agent

The Restaurant Agent handles restaurant and food-related information for the selected destination.

5. Itinerary Agent

The Itinerary Agent handles the final itinerary generation using the information collected during the planning process.

Sequential Processing

The Master Agent runs the specialized agents one after another:
Weather
   ↓
Budget
   ↓
Hotel
   ↓
Restaurant
   ↓
Itinerary

The state is passed from one agent to the next, allowing the later agents to work with the updated information.

Technologies

The agent workflow is implemented using Python and LangGraph-based agent components.

The agents communicate through a shared AgentState, which stores the information required during the travel-planning process.

## Shared Agent State

The agents use a common `AgentState` to pass information through the workflow.

The state contains the main travel inputs and the responses generated by each specialized agent.

### State Fields

| Field | Purpose |
|---|---|
| `destination` | Selected travel destination |
| `budget` | User's travel budget |
| `days` | Number of travel days |
| `weather` | Weather information |
| `response` | General response information |
| `budget_response` | Output from the Budget Agent |
| `hotel_response` | Output from the Hotel Agent |
| `restaurant_response` | Output from the Restaurant Agent |
| `itinerary_response` | Output from the Itinerary Agent |

### State Flow

The same state is updated as it moves through the agents:

```text
Initial Travel Information
        ↓
Weather information added
        ↓
Budget information added
        ↓
Hotel information added
        ↓
Restaurant information added
        ↓
Final itinerary generated

This shared-state approach allows each specialized agent to focus on its own task while keeping the travel information connected throughout the planning process.

### Budget Agent

The Budget Agent helps estimate the travel budget for the selected trip.

It takes the following information from the shared state:

- Destination
- User budget
- Trip duration

It then loads three datasets:

- `activity_cost.csv`
- `food_cost.csv`
- `transport_cost.csv`

The datasets are converted into readable text and included in a prompt sent to Gemini.

Gemini is asked to estimate:

1. Activity cost
2. Food cost
3. Transport cost
4. Total estimated budget
5. Whether the user's budget is sufficient
6. Money-saving tips

The generated budget report is stored in the shared state using:

```python
state["budget_response"]

Budget Agent Flow
User Budget + Destination + Days
              ↓
       Read Cost Datasets
              ↓
        Create AI Prompt
              ↓
          Gemini AI
              ↓
     Budget Recommendation
              ↓
       Update AgentState

The Budget Agent is implemented using a LangGraph state graph with a processing node that performs the complete budget-planning task.

### Weather Agent

The Weather Agent gets the current weather information for the selected destination using the Weather Service.

It first takes the destination from the shared `AgentState` and sends it to the Weather Service.

The returned weather information is stored in:

```python
state["weather"]

The weather data is then included in a prompt sent to Gemini AI.

Gemini generates exactly five travel recommendations covering:

What to wear
Whether to carry an umbrella
Places to visit in the current weather
Safety precautions
Local travel tips

The generated recommendations are stored in:

state["response"]
Weather Agent Flow
Destination
     ↓
Weather Service
     ↓
Current Weather Data
     ↓
Gemini AI
     ↓
5 Travel Recommendations
     ↓
Update AgentState

The Weather Agent is implemented as a LangGraph state graph with a processing node that performs the weather retrieval and recommendation generation.

### Hotel Agent

The Hotel Agent recommends hotels based on the selected destination and the user's budget.

It uses two destination datasets:

- `india_destinations.csv`
- `international_destinations.csv`

The agent searches both datasets for information related to the selected destination.

If matching information is found, the destination data is passed to Gemini through a prompt.

Gemini is asked to recommend five hotels and provide:

1. Hotel name
2. Approximate price per night
3. Rating
4. Nearby attractions
5. Reason for recommendation
6. Whether the hotel fits the user's budget

The agent also asks Gemini to select one best hotel overall.

The generated hotel recommendations are stored in:

```python
state["hotel_response"]

Hotel Agent Flow
Destination + Budget
        ↓
Search India Dataset
        ↓
Search International Dataset
        ↓
Destination Information
        ↓
Gemini AI
        ↓
5 Hotel Recommendations
        ↓
Best Hotel Recommendation
        ↓
Update AgentState

The Hotel Agent is implemented using a LangGraph state graph with a processing node.

### Restaurant Agent

The Restaurant Agent recommends restaurants based on the user's destination and budget.

It uses the `restaurants.csv` dataset and filters the data according to the selected destination.

The matching restaurant information is then sent to Gemini through a prompt.

Gemini is asked to provide:

1. Top 5 restaurants
2. Famous cuisines
3. Approximate cost for two
4. Veg / Non-Veg information
5. Ratings
6. Best restaurant overall
7. Why the recommendation suits the user's budget

The generated recommendations are stored in:

```python
state["restaurant_response"]

Restaurant Agent Flow
Destination + Budget
        ↓
Read Restaurant Dataset
        ↓
Filter by Destination
        ↓
Restaurant Information
        ↓
Gemini AI
        ↓
Restaurant Recommendations
        ↓
Update AgentState

The Restaurant Agent is implemented using a LangGraph state graph with a processing node.


### Itinerary Agent

The Itinerary Agent creates a day-wise travel itinerary based on the destination, budget, and trip duration.

It uses the `attractions.csv` dataset and filters the attractions according to the selected destination.

The matching attraction information is then provided to Gemini through a prompt.

Gemini is asked to create a complete day-wise itinerary.

For every day, it provides exactly one attraction for:

- Morning
- Afternoon
- Evening

For each attraction, the itinerary includes:

- Attraction name
- Category
- Approximate visit duration
- Entry fee
- Short reason for visiting

The itinerary is also requested to fit within the user's trip duration and budget.

At the end, Gemini provides three travel tips.

The generated itinerary is stored in:

```python
state["itinerary_response"]

Itinerary Agent Flow
Destination + Budget + Trip Duration
                ↓
      Read Attractions Dataset
                ↓
       Filter by Destination
                ↓
       Attraction Information
                ↓
             Gemini AI
                ↓
       Day-wise Itinerary
                ↓
          Travel Tips
                ↓
         Update AgentState

The Itinerary Agent is implemented using a LangGraph state graph with a processing node.
